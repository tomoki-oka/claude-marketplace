# bonsai

<p align="center"><img src="docs/bonsai.png" alt="右ドックで満開になった桜の盆栽" width="420"></p>

Claude Code の右ドックにピクセルアートの盆栽を出す Mod です。セッションごとに 1 鉢。開いている時間で育ち、答えが返るたびに飾りが増え、満開のあとは季節が巡ります。

## 入れ方

1. このフォルダを `~/.claude/skills/bonsai` に置く
2. Function Hooks を有効にする（Claude Code 2.1.274 以降）。`~/.claude/settings.json` に次を足すと素の `claude` で使える

```json
{ "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
```

3. 起動して `/bonsai` と打つ。この時点で植えられ、育ち始める

幅 110 列以上の全画面レイアウトで右ドック、狭いとプロンプト上に出ます。ターミナル専用です。

## コマンド

| コマンド | 動き |
|---|---|
| `/bonsai` | 出す・片付ける。最初に打った時点から育ち始める |
| `/bonsai speed <分>` | 満開までの分数（既定 480、全セッション共通、保存される） |
| `/bonsai clock real` | 木の一日を実時刻に合わせる（既定。19 時から 5 時が夜） |
| `/bonsai clock fast [分]` | 指定した分で一日が巡る（省略時 20 分）。開いている時間で回る |
| `/bonsai prune [番号]` | 枝を 1 本切る。番号を省くと乱数。しばらくすると切り口から 2 本生える |
| `/bonsai prune pick <番号>` | 切る枝を選んで強調表示だけする |
| `/bonsai seed` | この木の種を文字列で出す |
| `/bonsai plant <種> [種]` | 袋にある種から植え直す。2 つ渡すと交配した新種になる |
| `/bonsai bag` | 種袋。見頃を 1 巡するごとに、その木の種が 1 つ入る |
| `/bonsai bag add <種>` | もらった種を袋に入れる |
| `/bonsai badges` | 実績の一覧（全セッション共通） |
| `/bonsai species [id]` | 樹種の一覧、または植え替え（このセッションだけ） |
| `/bonsai name <名>` | 名札。省くとリポジトリ名が出る |
| `/bonsai shelf` | 盆栽棚を別の Pane に出す・片付ける。育てた木を小さく並べる（新しい順、最大 12 鉢）。一番下の `[ 戻る ]` で閉じる |
| `/bonsai reset` | このセッションの盆栽を鉢に戻す（樹形と樹種はそのまま） |
| `/bonsai debug <分> [spirit\|snow\|rain\|meteors\|clear]` | 検証用。累積時間を置き換え、精霊や天候を強制する |
| `/bonsai help` | この説明 |

## Pane のボタン

状態行の下に `[ ◁ ] [ ▷ ] [ 切る ] [ 水をやる ] [ 棚 ] [ 種袋 ] [ 実績 ]` が並びます。種袋は種のアイコン、実績は紋章が並ぶ Pane です。◁ ▷ で切る枝を選ぶと、その枝が黄色く点滅します。切る で確定です。Pane をクリックするか Ctrl+X Tab でフォーカスを移し、Enter かクリックで押します。押すとフォーカスはプロンプトに戻ります。ボタンからの水やりは 1 時間に 1 回です。

## 育ち方

- 鉢だけ → 芽 → 若木 → 育ち盛り → 成木 → 見頃。既定で 8 時間
- 見頃のあとは季節が巡る。各季節は満開までの時間の 4 分の 1。見頃 → 葉落ち → 冬木（雪）→ 芽吹き → 見頃
- 見頃を 3 巡すると古木（幹が太く、洞と苔）。累積 24 時間で神木（しめ縄と鳥居）
- resume すると閉じたときの状態から続く。閉じている間は育たない

## 作業との連動

| 出来事 | 木に起きること |
|---|---|
| Claude が答える | 飾りが 1 つ増える。答えが長いほど少し早く育つ（1 回最大 20 秒） |
| 見頃に答えが返る | 約 3%（33 回に 1 回）で樹種ごとの精霊が来て住みつく。答えのたびに少し動く |
| `git commit` が通る | 水やり。5 分ぶん伸びる |
| `rm -rf` や force push | 葉が 1 房落ちる |
| サブエージェントが答える | 幹に芽が 1 つ付く |
| 開いている時間 | 日照が 1 時間で 100% ぶん下がる（下限 30%）。低いと葉がくすむ |
| 答えが返る、commit が通る | 日照が 15%、50% 戻る |
| 見頃を 1 巡する | その木の種を袋に収穫 |
| コンテキストが 80% を超える | 葉が黄ばみ、「休憩どき」と 1 回知らせる |
| コンテキスト圧縮（忘却の木のみ） | 葉が全部散り、芽からやり直し |

節目（見頃、季節替わり、黄ばみ始め）はトーストで 1 回ずつ知らせます。

## 実績

全セッション共通で 11 個。達成するとトーストで知らせ、`/bonsai badges` で見られます。

初花（初めて見頃）、十樹種（10 樹種を見頃に）、神木、剪定二十、精霊五、交配、種十（10 個収穫）、珍種（珍しい樹形を見頃に）、四季（1 年巡る）、十時間、百時間（総育成時間）。実績 Pane では紋章が並び、達成は色付き、未達は灰色です。総育成時間も出ます

## 樹種

セッション ID で決まります。約 3% のセッションで架空の樹種（星降りの木以下）になり、それ以外は現実の樹種です。`/bonsai species <id>` で植え替えられます。

## 空と天候

- 木の時計で 19 時から 5 時は夜。右上に小さな月だけ出る。背景は塗らない
- その日の天候は日付で決まる。雪 3%、雨 5%、見頃の夜なら流星 3%。ほとんどの日は晴れ

## 保存

- セッション ID をキーに、育ち具合、飾り、剪定、傷、芽、精霊、名札、植えた種を保存する
- 満開までの分数と時計モードは全セッション共通
- 書き込みは 10 秒ごとと出来事のたび。最悪 10 秒ぶん巻き戻る

## 注意

- Function Hooks は早期アクセスの API で、Claude Code の更新で動かなくなることがある
- 描画は Raster を使うため、デスクトップアプリや VS Code では出ない
